# Todok

Todok은 키보드 입력에 타건음을 더해주는 Windows 및 macOS용 데스크톱 애플리케이션입니다.

## Download

최신 버전은 [GitHub Releases](https://github.com/somedding6363/todok-release/releases/latest)에서 다운로드할 수 있습니다.

- **Windows:** Windows x64
- **macOS:** macOS 14.2 이상, Apple Silicon

## Updates

Todok은 새로운 버전이 출시되면 앱 내에서 업데이트를 안내합니다.

## Notice

현재 배포 파일은 공식 코드 서명 및 공증을 거치지 않았으므로, 설치하거나 처음 실행할 때 운영체제의 보안 경고가 표시될 수 있습니다.
